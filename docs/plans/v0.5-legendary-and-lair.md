# v0.5: Legendary actions, recharge and lairs

**Status: built and verified in test-5e-world (2026-11-14). In v0.9 the Legendary Prompt was replaced by the Legendary Menu, opened by hovering a monster's pips (see PLAN.md).** Changes from the plan, found while testing: a legendary action button skips dnd5e's "Consume Legendary Action?" dialog (`configure: false`), since the button already shows the cost; spells a feature casts (`flags.dnd5e.cachedFor`) are left out of the buttons; and a Stat Block that would cover the Prompt moves down below it.

The goal: at a table with physical minis, the GM never forgets a legendary action, a recharge or a lair bonus. Terms are in [CONTEXT.md](../../CONTEXT.md); the spec lines are in [PLAN.md](../../PLAN.md) › Running a fight.

## Decisions (agreed 2026-11-14)

- **Legendary indicator:** GM-only pips under a legendary monster's Carousel card, showing uses left.
- **Legendary Prompt:** a small GM-only strip under the Carousel. It appears when a turn ends and clears at the next turn. Each legendary monster that didn't just act gets a row with its pips and its legendary actions as buttons (with their cost). A click uses that action through dnd5e, which spends the uses.
- **Recharge:** dnd5e already rolls recharge at the start of a monster's turn, but its world setting `autoRecharge` defaults to "no". Encounter Deck asks the GM once to turn it on, like it does for Monk's TokenBar. During a monster's own turn, the Legendary Prompt also lists its recharge abilities as ready or spent ("Fire Breath · 5–6").
- **Lairs use the 2024 rules:** there's no Lair turn at initiative 20. An Encounter has an **In its lair** checkbox. Import then marks every imported monster that has a lair (`system.resources.lair.value`) as inside it. dnd5e then adds +1 legendary action and +1 legendary resistance by itself. This applies to 2014 monsters too.

## What dnd5e 5.3.2 already does (reuse, don't rebuild)

- `system.resources.legact` (`max`, `spent`, derived `value`) and `legres` on NPCs. Spent legendary actions reset at the end of the monster's own turn (`NPCData#recoverCombatUses`, `turnEnd`).
- Activities with activation type `legendary` (or `mythic`) consume `resources.legact` by their activation value. Using one through `activity.use()` spends the uses.
- Recharge: `UsesField.rollRecharge` runs at `turnStart` for NPCs when `dnd5e.autoRecharge` is "silent" or "yes".
- Lair: `resources.lair.value` (has a lair), `lair.inside`, and `lair.initiative` (2014, unused here). When `value && inside`, `legact.max` and the legendary resistance item's uses go up by 1 in data prep.
- The SRD 2014 and 2024 Adult Red Dragons both have `legact.max` 3 and `lair.value` true, Detect/Tail Attack (cost 1) and Wing Attack (cost 2) as legendary activities, and Fire Breath with recharge 5.

## Build steps

1. **Pure model, `module/src/legendary.ts`, with `module/test/legendary.test.ts`:**
   - `legendaryOf(actorData)` returns `{ value, max }`, or null when `max` is 0.
   - `legendaryActions(items)` returns `{ itemId, activityId, name, img, cost }[]` from activities with activation `legendary`/`mythic`, sorted by cost and then name.
   - `rechargeAbilities(items)` returns `{ name, ready, label: "5–6" }[]`.
   - `promptRows(combatants, endedId)` returns which monsters get a row: they have legendary uses left, they aren't defeated, and they aren't the one whose turn just ended. Hidden ones are fine, since the Prompt is GM-only.
   - `lairDelta(hasLair, inLair)` returns the token delta `{ system: { resources: { lair: { inside: true } } } }` or null.
2. **Encounter flag:** add `inLair: boolean` (default false) to `EncounterFlags`, plus an "In its lair" checkbox in `builder-details.hbs`. Saving goes through the Builder's existing `saveFlags`. Show a small lair icon on the encounter row in the browser.
3. **Import (`importer.ts`):** for each token from an actor whose `system.resources.lair.value` is true, put `lairDelta(...)` into `getTokenDocument`'s data. Tokens are already unlinked, so this never touches a world actor. Reinforcements read the flag of the Encounter they come from.
4. **Carousel card (`carousel-model.ts`, `carousel.hbs`, CSS):** add `legendary: { value, max } | null` to `CombatantInput`, and to `CardView` for the GM only. Draw gold pips under the card, filled for uses left. Add `buildCards` tests: GM sees pips, players never do.
5. **Legendary Prompt (`ui/carousel.ts` + `carousel.hbs`):** a GM-only part under the strip. It's driven by `updateCombat` when the turn or round changes. Remember `endedId` (the previous `combat.combatant`), build rows with `promptRows`, and keep them until the next turn change or until ✕ is clicked. Buttons run `actor.items.get(itemId).system.activities.get(activityId).use({ event })`. A button is disabled when its cost is more than the uses left. A second section for the current monster's recharge abilities shows only during its own turn.
6. **Live updates:** the pips and Prompt must re-render when a token actor's `legact.spent` or an item's uses change. Unlinked tokens update through the ActorDelta, so check which hooks fire (`updateActor` on the synthetic actor, `updateActorDelta`, `updateItem`) and add the missing ones to the Carousel's refresh list.
7. **Ask once about recharge:** when the GM loads the world, if `dnd5e.autoRecharge` is "no" and `rechargeAsked` (a new world setting) is false, ask "Let dnd5e roll monster recharge at the start of their turns?" Yes sets it to "yes". Either answer sets `rechargeAsked`. This follows `checkTokenBar` in `finish.ts`.
8. **Docs and version:** update PLAN (spec lines and Roadmap v0.5), CONTEXT (Legendary Prompt, In its lair), README ("What v0.5 adds"), and set `module.json` to 0.5.0.

## Verify in test-5e-world

- `npm run typecheck`, `npm test`, `npm run build`.
- Build a test Encounter with the 2014 and the 2024 Adult Red Dragon, Goblins and the party, with "In its lair" on, then Import it. Both dragons should show `legact.max` 4, legendary resistance 4, and four gold pips.
- Advance turns:
  - After a Goblin's turn, the Prompt lists both dragons.
  - After a dragon's own turn, only the other dragon is listed.
  - Tail Attack spends 1 and Wing Attack spends 2. Pips and buttons update, and Wing Attack is disabled at 1 left.
  - A dragon's spent uses come back after its own turn (dnd5e).
- With recharge turned on, Fire Breath used → at the dragon's next turn start dnd5e rolls, and the Prompt shows ready or spent.
- As the player ("Claude Test Player") or through the Carousel's viewer model, check that players never see the pips or the Prompt.
- Finish removes everything as before. Afterwards restore `dnd5e.autoRecharge` to "no", reset `rechargeAsked`, and delete the test Encounter and combat.

## Not in v0.5

- A Lair turn at initiative 20 (2014 rules) and lair-action buttons. The 2024 rules don't use them, and the SRD has no lair-action items.
- Legendary resistance prompts on failed saves. The legendary resistance count is still visible on the Stat Block.
- Players seeing legendary uses.
